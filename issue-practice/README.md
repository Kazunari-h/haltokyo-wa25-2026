# イシュー投稿練習用ページ集

架空のカフェ「HAL Cafe」のWebサイトという設定で、**意図的に不具合を仕込んだHTMLファイルが30個**あります。
ページを開いて不具合を見つけ、GitHubのIssueとして報告する練習をしてください。

## 使い方

1. このリポジトリをクローン（またはZIPでダウンロード）する
2. `issue-practice/01-index.html` をブラウザで開く
3. 各ページを操作して「説明どおりに動かない」「表示がおかしい」箇所を探す
4. 見つけた不具合を1件ずつIssueとして投稿する

各ページには「こう動くはず」という説明文が書いてあります。説明と実際の動きのズレが不具合です。
1ページに複数の不具合が入っていることもあります。

## Issueに書くべき内容

- **タイトル**: どのページで何が起きるかが一目でわかるように（例: `[07-pricing] 税込合計が正しく計算されない`）
- **対象ファイル**: `issue-practice/07-pricing.html` のようにパスで書く
- **再現手順**: 誰がやっても同じ結果になるように、番号付きで
- **期待する結果**: 本来どうなるべきか
- **実際の結果**: 実際にどうなったか（スクリーンショットがあるとなお良い）
- **環境**: ブラウザ名とバージョン、OS

### 例

```
タイトル: [09-counter] 「+」ボタンを押すとカウントが減る

対象ファイル: issue-practice/09-counter.html

再現手順:
1. 09-counter.html をブラウザで開く
2. 「+」ボタンを1回クリックする

期待する結果: カウントが 0 → 1 になる
実際の結果: カウントが 0 → -1 になる

環境: Chrome 140 / macOS 15
```
